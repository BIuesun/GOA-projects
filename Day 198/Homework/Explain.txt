1. რა არის HashMap?
HashMap არის მონაცემთა სტრუქტურა, რომელიც ინახავს Key-Value წყვილებს. იგი ძალიან სწრაფად (საშუალოდ O(1)) აღმოაჩენს, ამატებს და შლის ელემენტებს გასაღების მიხედვით.

2. როგორ ინახავს HashMap მონაცემებს?
HashMap იყენებს hash table-ს (ჰეშ-ცხრილს).

თითოეული Key-ს გამოითვლება hash code.
ამ hash code-ის მიხედვით ელემენტი ინახება კონკრეტულ უჯრაში (bucket).
თუ რამდენიმე ელემენტი ერთ უჯრაში მოხვდება (collision), ისინი ინახება linked list-ად ან tree-ად (Java 8+).

3. რას ნიშნავს Key და Value?

Key  უნიკალური იდენტიფიკატორი (გასაღები), რომლითაც ვეძებთ მონაცემებს.
Value  მნიშვნელობა, რომელიც ინახება ამ გასაღებთან დაკავშირებით.

მაგალითი: studentId → studentName

4. შეიძლება თუ არა HashMap-ში ერთნაირი Key-ების შენახვა?
არა. Key-ები უნიკალური უნდა იყოს. თუ იგივე Key-ით ახალ ელემენტს დაამატებ, ძველი Value გადაიწერება.

5. შეიძლება თუ არა HashMap-ში ერთნაირი Value-ების შენახვა?
დიახ. Value-ები შეიძლება იყოს დუბლირებული. რამდენჯერაც გინდა შეგიძლია ერთნაირი მნიშვნელობები შეინახო.
