1. რა არის HTTP?
HTTP (HyperText Transfer Protocol) არის წესების სისტემა (პროტოკოლი), რომლითაც ვებ-ბრაუზერი და ვებ-სერვერი საუბრობენ ერთმანეთთან.
მარტივად: ეს არის „ენა“, რომლითაც შენი ბრაუზერი სთხოვს სერვერს გვერდს ან მონაცემებს, და სერვერი პასუხობს. HTTP არის ვებ-ინტერნეტის საფუძველი მის გარეშე ვერ გაიხსნებოდა არც ერთი ვებსაიტი.


2. განსხვავება HTTP Request-სა და HTTP Response-ს შორის

HTTP Request  მოთხოვნა, რომელსაც კლიენტი (ბრაუზერი) უგზავნის სერვერს.
HTTP Response  პასუხი, რომელსაც სერვერი უბრუნებს კლიენტს.

GET იღებს მონაცემებს სერვერიდან (გვერდის ჩატვირთვა, ინფორმაციის წაკითხვა)
POST აგზავნის ახალ მონაცემებს სერვერზე (ფორმის გაგზავნა, რეგისტრაცია, პოსტის დამატება)
PUT ანახლებს ან ცვლის არსებულ მონაცემებს სერვერზე (მთლიანად ჩანაცვლება)
DELETE შლის მონაცემებს სერვერიდან
